# Todas as classes, estágios e concessões

Transcrição dos campos operacionais de `modules/class-system/config/classes-config.json`. Não representa liberação dos efeitos no servidor. A elegibilidade usa nível de personagem; os patamares de skills e o tratamento de “Todas” são discutidos em [progressão](06_CLASSES_PROGRESSAO.md). Perks são nomes de configuração e devem atravessar a [matriz de identidade](CLASS_PERK_MAPPING.md).
